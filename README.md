# OpenFOAM Complete Course

Welcome to the **OpenFOAM Complete Course – From Zero to Advanced CFD Simulations!**

This repository contains the tutorial case files used in my YouTube course, covering OpenFOAM fundamentals and advanced CFD applications.

### Topics Covered

- OpenFOAM installation and configuration
- Mesh generation (blockMesh and snappyHexMesh)
- Running simulations and post-processing with ParaView
- Parallel computing
- Conjugate heat transfer (CHT)
- Multiphase flow (VoF and Eulerian–Eulerian)
- Porous media and dynamic mesh
- Lagrangian particle simulations

### How to Use

1. Download the repository using **Code → Download ZIP**.
2. Extract the files.
3. Open the desired tutorial case in OpenFOAM.
4. Follow the corresponding section of the YouTube course.
